# NacreCraft.Native

The native layer that enters the process before any managed code. The managed side sets the `CORECLR_*` profiler variables and restarts, and the runtime loads this library as a profiler at startup; there is no external injector. It carries the stack-overflow guard, the crash path that survives a hardware fault, and a ReJIT executor that stays off unless `NCN_REJIT` asks for it.

## Features

- Early entry — loaded through `CORECLR_ENABLE_PROFILING`, `CORECLR_PROFILER` and `CORECLR_PROFILER_PATH`, which the managed side writes before restarting. `ncn_on_initialize` is the first code the process runs.
- Stack-overflow guard — the vectored exception handler is installed only after the managed side hands over its callback, so it sits in front of the runtime's own handler; the overflow is then reported on a thread that still has stack.
- Machine-code stack guard (default) — `src/hook` moves the check to the method's native entry: `JITCompilationFinished` hands the code address over, the first bytes become a jump to a trampoline nearby, and the trampoline either replays the displaced instructions or jumps to a managed throw entry. A method the JIT inlined has no entry, so it is never checked. `NCN_REWRITE_MODULES` narrows the hooked assemblies and `NCN_STACK_RESERVE` sets the bytes kept above the guard page (default 512 KB); `NCN_STACK_CHECK=0` turns the guard off, with `NCN_STACK_HOOK=0` and `NCN_STACK_GUARD=off` as aliases. Windows x64 only. The checks live in `p0/`, the server comparison in `p1/`, and the overflow comparison in `p2/`.
- Runtime rewrite — off by default. The runtime only accepts `COR_PRF_ENABLE_REJIT` together with `COR_PRF_DISABLE_ALL_NGEN_IMAGES`, which keeps every ReadyToRun image from loading and sends the whole framework back through the JIT; that cost lands on any hot path dominated by framework code, and nothing requests a rewrite unless `NCN_REJIT` is set. With it set, `ncn_request_rewrite` takes a method-body description, waits for its module to load, asks the runtime for ReJIT and answers the `GetReJITParameters` callback with the new body. Requests are fulfilled on a thread of this module, because entering the profiling API from a managed thread would re-enter the runtime.
- Crash path — `crash` records hardware faults managed code cannot survive, `report` writes the report once managed code can no longer run, `logging` keeps one diagnostic file, and `ui` shows the egui window with copy, open-folder and close actions. `icon` extracts the window icon from the running executable.
- C++ shell — `shell/` owns the profiler COM object (`ICorProfilerCallback10`), takes the JIT-compilation and module-load events, adds the ReJIT pair only when `NCN_REJIT` is set, and forwards every callback into the Rust core.
- Build — `build.ps1` produces `out/<rid>/nacrecraft_native.dll` (or the platform equivalent). The publish targets copy it to `runtimes/<rid>/native`.
